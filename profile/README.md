**The word processor that complements Word and Google Docs, or replaces them.** Your `.docx` files stay `.docx` files;
your AI agents write in them too. Made in France — [paginel.com](https://paginel.com).

These repositories publish built files, documentation and examples. The source code is not public.

| Repository | What you get |
|---|---|
| [**paginel-text**](https://github.com/paginel/paginel-text) | The **Paginel Text** desktop app: installers for macOS, Windows and Linux. Free, no account needed. |
| [**paginel-cli**](https://github.com/paginel/paginel-cli) | **Paginel Text – CLI**: `paginel-text` fills Word templates (`{{placeholders}}`) with Markdown and JSON, to `.docx` or PDF, offline, for your scripts, servers and agents. Linux and Windows. |
| [**orca-plugins**](https://github.com/paginel/orca-plugins) | The Paginel Text plugin for [Orca](https://github.com/stablyai/orca), the editor for agents: open `.docx` and Markdown files in Orca. |

Also: the [VS Code extension](https://marketplace.visualstudio.com/items?itemName=paginel.paginel-text), and
[paginel.com](https://paginel.com) to write together online. Contact: hello@paginel.com.

**En français** : le traitement de texte qui complète Word et Google Docs, ou les remplace. Ici : l'application de bureau
